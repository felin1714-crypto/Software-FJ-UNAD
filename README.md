
# SISTEMA SOFTWARE FJ

## Descripción del proyecto

Software FJ es una aplicación desarrollada en Python mediante programación orientada a objetos y la biblioteca Tkinter.

El sistema permite gestionar clientes, servicios y reservas mediante una interfaz gráfica.

## Objetivo

Desarrollar una aplicación que permita administrar las operaciones del sistema, aplicando el manejo de excepciones para controlar errores y mejorar la estabilidad del programa.

## Funcionalidades

- Registro de clientes.
- Gestión de servicios.
- Administración de reservas.
- Manejo de excepciones personalizadas.
- Validación de datos.
- Registro de eventos y errores.
- Pruebas de funcionamiento.
- Interfaz gráfica con Tkinter.

## Tecnologías utilizadas

- Python.
- Tkinter.
- Programación orientada a objetos.
- GitHub.

## Cómo ejecutar el programa

1. Tener Python instalado.
2. Descargar el archivo del repositorio.
3. Abrir la terminal en la carpeta donde está guardado.
4. Ejecutar:

```bash
python sistema_software_fj.py
```
